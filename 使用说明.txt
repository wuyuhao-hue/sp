定时按回车 - Windows小工具

一、使用方法
1. 双击「启动工具.bat」（或直接双击「定时按回车.pyw」）。
2. 在执行时间输入 02:00:00（24小时制）。
3. 建议锁定窗口：点击「5秒后锁定目标窗口」，然后在5秒内切换到需要按回车的软件。
4. 切回工具点击「开始定时」。然后尽量让目标软件保持前台。
5. 到 02:00:00，工具向目标窗口发送一次 Enter。只执行一次。
6. 取消时点击「取消定时」。

二、重要提示
- 时间以 Windows 电脑本地时钟为准，不更改系统时间。
- 如果今天02:00:00已经过了，将安排到明天02:00:00。
- 软件需一直运行，电脑需保持开机、不休眠、不锁屏。
- 目标应用需保持运行，处于能接收键盘输入的状态。
- 如果目标程序以管理员身份运行，普通权限的工具可能无法发送按键。必要时用管理员权限运行本工具。
- Windows前台窗口切换受系统限制：自动激活失败时，为防止误操作其他软件，工具不会发送按键。
- 执行时间通常接近目标秒，但 Windows 不是实时系统，不承诺绝对零误差。
- 无需安装第三方 Python 库，使用 Python 3 自带 tkinter 和 ctypes。
