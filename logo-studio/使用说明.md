# 印标工作台 使用说明

采集 1688 服装商品（主图、SKU 图、SKU 名称、尺码、价格、标题），一键把**你自己的商标**印到衣服左胸，导出后上架 Wildberries。
定位和印标全部在本地完成，**不需要中转站，不花钱**。

## 启动

1. 双击仓库根目录的 **`启动印标工具.bat`**。
2. 第一次运行会自动：
   - 检查 Python（没有就用 winget 自动安装 Python 3.12，装完重新双击即可）
   - 创建独立运行环境并安装依赖（约 150MB，国外源慢会自动切换清华/阿里镜像）
3. 浏览器自动打开 `http://127.0.0.1:8765`。**使用期间不要关闭黑色命令行窗口。**

## 安装「采集助手」Chrome 扩展（一次就好）

采集在你自己日常用的 Chrome 里进行，直接用你已登录的 1688 账号，不需要另开浏览器，也没有任何自动化标记。

1. 在 Chrome 地址栏输入 `chrome://extensions` 打开扩展页面。
2. 打开右上角的「开发者模式」。
3. 点「加载已解压的扩展程序」，选择程序目录里的 `logo-studio\chrome-extension` 文件夹。
4. 回到印标工作台页面按 F5 刷新，右上角显示「采集助手已连接」就好了。

> 以后更新程序时，扩展页里点一下「采集助手」上的刷新按钮即可。

## 使用流程

1. **上传 Logo**：「Logo 库」页拖入你的商标图片（透明底 PNG 最好；白底 JPG 会自动抠底）。
   - 颜色「自动深浅」：浅色衣服印深色 logo，深色衣服印浅色 logo。
   - 可以给每个 logo 单独上传「浅色版」「深色版」，不传就自动生成白色和黑色版本。
   - 可以调整工艺（印花 / 刺绣）和默认大小。
2. **采集商品**（三种方式，都在你自己的 Chrome 里进行）：
   - **商品页一键采集**：在 Chrome 里逛 1688，看中的商品页右下角有「采集到印标工作台」按钮，点一下即可。
   - **采集已打开的标签页**：先在 Chrome 里打开一批商品页，然后在工作台点「采集 1688」→「采集已打开的标签页」。
   - **批量 / 整店采集**：在「采集 1688」里粘贴商品链接（一行一个，也可以粘贴一大段包含链接的文字），或填店铺链接。采集助手会在一个**最小化的窗口**里逐个打开商品页读取数据，不影响你正常上网。
   - 遇到登录或人机验证时，那个窗口会自动弹出来，处理完会自动缩回去继续采集。
   - 采集进度显示在右下角，每个商品都会显示"正在打开第几个"。
   - 也可以点「导入图片」，直接用本地图片试效果。
3. **印标**：左侧选商品，右侧点 logo，所有识别为"可印"的图会立刻印上。
   - 再点别的 logo 会**从原图重新生成**，不会叠加；点「不印 / 恢复原图」回到原图。
   - 位置不对：直接在图上拖动虚线框，右下角小方块可以调大小。
   - **同款一次调好**：同一商品不同颜色的图构图通常一样，调好一张后点「同步到同款图」，其余图会按衣服轮廓自动换算到相同位置。
   - **自动学习你的习惯**：你手动调整过 3 张以上后，之后新识别的商品会自动按你的习惯修正（比如你总是往右上挪一点）。学到了什么可以在「设置 → 定位学习」里看到，也可以清除。
   - 细节图、背面图会自动跳过；识别错了可以用「这张图印 logo」开关手动改。
   - 按住图片空白处可以对比原图；键盘 ← → 切换图片，↑ ↓ 切换商品。
4. **批量**：左侧勾选多个商品，底部可以批量印标、恢复原图、导出、删除。
5. **导出**：每个商品一个文件夹，外加一张 `商品汇总.xlsx`（标题、SKU、颜色、尺码、价格、库存、图片文件）。
   默认把图片转成 WB 要求的 3:4、900×1200（可在设置里关闭）。导出目录在 `logo-studio/data/exports`。

## AI 精修（可选）

在「设置」里填写中转站地址、Key 和模型名（如 `gpt-image-2`）后，印标页的「AI 精修」按钮会让 AI 重新融合单张图的 logo 区域。
程序只把 logo 周围一小块换成 AI 的结果，衣服其它部分保持原样。每次调用都会产生费用，不配置也不影响其它功能。

## 常见问题

- **定位不准的商品很多**：「设置 → 定位学习 → 导出定位调试包」，把生成的 zip 发给开发者，用你的真实图片一次性批量调优。
- **出错提示**：界面上会显示具体原因，完整信息记录在 `logo-studio/data/logs/error.log`，反馈问题时附上这个文件。
- **采集失败 / 解析失败**：1688 页面结构会不定期调整。失败的商品会在 `logo-studio/data/debug/` 里留下一个调试文件，发给开发者即可适配。
- **验证码频繁**：在设置里调大「每个商品间隔」（默认 3 秒，实际会在 3~6 秒间随机）。同一个账号一天不要采太多。
- **不想装扩展**：「设置 → 采集方式」可以切换为「独立浏览器窗口」，程序会单独打开一个 Chrome 窗口采集（需要在里面登录一次）。
- **数据在哪**：全部在 `logo-studio/data/` 文件夹（商品、logo、导出、设置），备份或迁移时复制这个文件夹即可。
- **部署到服务器**：设置环境变量 `LOGO_STUDIO_HOST=0.0.0.0` 后运行 `python -m app`。注意采集功能需要有图形界面的浏览器。

## 说明

请只使用你拥有或已获授权的商标。图片上印了 logo，实际发货的商品也应带有相同的 logo，避免图文不符。
