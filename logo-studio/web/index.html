还没有安装「采集助手」Chrome 扩展，装一次就行：
1. 在 Chrome 地址栏输入 chrome://extensions 打开扩展页
2. 打开右上角的「开发者模式」
3. 点「加载已解压的扩展程序」，选择程序目录里的 logo-studio\chrome-extension 文件夹
4. 回到本页面按 F5 刷新
采集在你自己的 Chrome 里进行，使用你已登录的 1688 账号：会自动打开一个最小化的窗口逐个读取商品页，不影响你正常上网。遇到登录或人机验证时这个窗口会弹出来，处理完会自动缩回去继续。只保存图片链接，不下载图片。
