采集 1688 商品

还没有安装「采集助手」Chrome 扩展，装一次就行：
1. 在 Chrome 地址栏输入 chrome://extensions 打开扩展页
2. 打开右上角的「开发者模式」
3. 点「加载已解压的扩展程序」，选择程序目录里的 logo-studio\chrome-extension 文件夹
4. 回到本页面按 F5 刷新
采集在你自己的 Chrome 里进行，使用你已登录的 1688 账号：会自动打开一个最小化的窗口逐个读取商品页，不影响你正常上网。 遇到登录或人机验证时这个窗口会弹出来，处理完会自动缩回去继续。
更省事：浏览 1688 时，商品页右下角有「采集到印标工作台」按钮，点一下就采集；或者开好多个商品标签页后，点左下角「采集已打开的标签页」。
会打开一个独立的 Chrome 窗口（和你平时用的 Chrome 互不影响）。第一次使用请在窗口里登录 1688（建议用小号），之后会记住登录状态。遇到人机验证时在窗口里手动完成，程序会自动继续。
最不容易触发验证的方式：自己在这个窗口里打开想要的商品页（可以开很多个标签页），然后点左下角「采集已打开的标签页」，程序不做任何跳转，只读取页面数据。
